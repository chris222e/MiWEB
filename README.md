# MiWEB

Este proyecto es una práctica de estructura básica de un sitio web con **HTML, CSS y JavaScript**.

## 📂 Estructura del Proyecto

```
MiWEB-main/
│
├── css/          # Estilos CSS
├── js/           # Funciones JS
├── images/       # Recursos gráficos
├── index.html    # Página principal
├── login.html    # Página de inicio de sesión
├── register.html # Página de registro
└── README.md     # Documentación
```

## 🚀 Descripción

- **index.html**: Avance de la página principal.  
- **login.html**: Formulario para iniciar sesión.  
- **register.html**: Formulario para registrar un usuario.  

## 📌 Instrucciones

1. Clonar o descargar el repositorio.  
2. Abrir `index.html` en el navegador.  
3. Navegar entre las páginas usando el menú superior.

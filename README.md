# 🎃 MiWeb - Proyecto Terror Night

**Descripción:**  
MiWeb es una página web temática de **películas y videos de terror**.  
Incluye secciones como carrusel de películas, videos destacados, historias de terror, top 5 de películas, comentarios de visitantes, mapa de ubicación y un formulario de contacto.  
La web ofrece una **experiencia oscura y envolvente**, ideal para los fanáticos del género.  

---

**Estructura del proyecto:**  
- **index.html**: Página principal del sitio  
- **css/**: Estilos CSS personalizados  
- **js/**: Scripts JavaScript adicionales  
- **imagenes/**: Imágenes usadas en la web  
- **.gitignore**: Archivos a ignorar en Git  

---

**Tecnologías utilizadas:**  
- HTML5  
- CSS3  
- JavaScript  
- Bootstrap 5  

---

**Características principales:**  
- 🎡 Carrusel de películas de terror  
- 📹 Video destacado del día  
- 📖 Historias de terror con tarjetas  
- 🏆 Top 5 películas con calificaciones  
- 💬 Comentarios de visitantes  
- 📨 Formulario de contacto funcional  
- 🗺 Mapa integrado de Google Maps  
- 🔝 Botón flotante para subir al inicio  
- 🌑 Tema oscuro para mejorar la experiencia visual
